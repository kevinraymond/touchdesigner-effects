# blob_track: idiom review

Reviewed version: 0.1.2

The review items of docs/TD_IDIOMS.md, checked by hand for this version: tick each box
(`- [x]`) and say in a few words how it holds.

- [x] P4 Pulse for actions, Toggle for states, Menu for discrete choices; labels in Title Case. Names of 10 characters or fewer are checked at save time (assert_idiomatic); TouchDesigner itself refuses names that aren't an uppercase letter followed by lowercase letters or digits. [Custom Parameters](https://docs.derivative.ca/Custom_Parameters), [Page Class](https://docs.derivative.ca/Page_Class)
  Pulses for Open Window and Open Docs; Toggles for Scramble Labels, Spawn Links, Fill Boxes, Song Moments and Full Screen; Menus for Detector, Track, Picture, Inside, Labels, Links, Accent and Flashing; Float/Int for amounts and sizes. Labels in Title Case; the longest name is Beatlabels (10), and the build passes the save-time check.
- [x] P5 Inner operators follow the COMP's parameters through expressions (`parent().par.Amount`), not scripts copying values; values only the inside needs are kept off the pages (`ipar`). [Internal Parameters](https://docs.derivative.ca/Internal_Parameters)
  Every inner operator follows the page through expressions: GLSL uniforms (parent().par.X and .menuIndex), the Blob Track TOP's threshold, the merge blur's size, the detector Switch's index, the flash triggers' gains and spacing. The only script is lib's parexec for the two pulses. Slot counts, tracker resolution, show-after, hold and fade times, the background's two paces, flash spacing, colors and words stay in the builder and shaders, off the page. 0.1.1 adds Max Count to track's uniforms (an expression, like the rest).
- [x] P6 Related parameters are grouped with `startSection`; parameters that don't apply in the current mode are grayed out with `enableExpr`.
  Sections: Detector to Smoothing, Picture to Accent, Scramble Labels to Song Moments, then Flashing and the window. Checked in TouchDesigner (dev/protos/blob/pass2/checks.py): Merge is grayed out for GPU Grid, Label Size and Scramble Labels while Labels is Off.
- [x] I4 The audio input goes through `audio_in()`, which reads it by channel name with fallbacks and takes a pulse from its count channel when one exists, because a one-frame pulse is lost on any frame nothing pulls the CHOP; the effect reads the counts (`beat_count`, `bar_count`...) for logic, not `beat`. [Cook](https://docs.derivative.ca/Cook), [Logic CHOP](https://docs.derivative.ca/Logic_CHOP)
  Input 2 goes through audio_in(). counts selects beat_count, bar_count, drop_count and section_count; a time-sliced Slope CHOP (steps) turns each rise of a count into a one-frame step for the Trigger CHOPs, and the counts seed the scrambles, words and partners in the shaders. The beat channel is never read. 0.1.2 changes only lib/audio_callbacks.py (#4652): raw audio's beats now come from a beat clock locked to the kicks' tempo (bars every 4 of its beats), and Fosfora's level from its bass. Its logic is unchanged here. Checked by dev/selftest.py (every input kind, Fosfora's level from bass) and dev/beat_bench.py --selftest.
- [x] E2 Only capitalized members are promoted; state lives on `self` and the extension can be reinitialized at any time; no module globals; `onInitTD`/`onDestroyTD`, the 2025 names. [Release Notes 2025](https://docs.derivative.ca/Release_Notes/2025.30000)
  No extension in this effect, so nothing to promote or reinitialize.
- [x] C4 Motion and timing follow seconds (`absTime.seconds`, `me.time.seconds`), not frame counts, so dropped frames don't change the speed. [AbsTime Class](https://docs.derivative.ca/AbsTime_Class)
  Checked in TouchDesigner (pass2/checks.py): every Trigger CHOP length is in seconds and the Slope CHOP is time-sliced. The background (both its paces and the stillness that picks between them), grid smoothing, box gliding and coasting, show-after delay, hold and fades step by absTime.stepSeconds; scrambles and labels follow absTime.seconds; the Blob Track TOP's revive time is in seconds. Nothing counts frames.
- [x] C5 Nothing cooks while the output is unused: checked with dev/idle.py (nothing downstream, the node out of view; input 2 unwired and wired to a changing beat), or in the Performance Monitor. [Performance Monitor](https://docs.derivative.ca/Performance_Monitor_Dialog)
  dev/idle.py on the 0.1.1 build (node viewer off, nothing downstream): 0 of 92 operators cooked over 60 frames unused with input 2 unwired, and 0 with the clip and a beat changing every frame wired in; the control (pulling out_top) cooked 54 and 55. dev/idle.py on the 0.1.2 build: 0 of 92 operators cooked over 60 frames unused, unwired and wired; control 54 and 55.
- [x] C6 Pixel formats are 8-bit unless precision is needed, and 32-bit float for data textures (a CHOP to TOP feeding a shader).
  8-bit for the pictures: small, local_mean, mask, merge, background and the output. 32-bit float for data: state (frame, background, seconds since a change), grid, grid_peaks, blob_data, bt_clean, bt_pick, grid_pick, match, track, track_start, table and tiles.
- [x] C7 The performance note on the docs page was measured on the reference machine at 1280 x 720, not estimated.
  dev/perf.py on the 0.1.1 build (MacBook Pro M2 Pro 16 GB, macOS 15.6, TouchDesigner 2025.33230), 1280 x 720, defaults: GPU 2.28 ms (95th percentile 3.64), CPU 0.98 ms (1.18), 60 fps held; blobs 0.81 ms and draw 0.66 ms the most, track under 0.1 ms. GPU Grid (Detector=grid): GPU 1.37 ms (1.93), CPU 0.38 ms (0.38). The last rebuild changed only the README DAT. dev/perf.py on the 0.1.2 build, demo paused (2026-10-24): GPU 3.87 ms (95th percentile 5.29), CPU 0.79 ms (1.02), 60 fps held. The change is Python in the audio input's Script CHOP (CPU, once a cook); GPU times on this Mac swing about a third between runs with the GPU's clock (Datamosh 2.8 to 4.0 ms on one build), so the docs page keeps the published numbers.
- [x] D5 The README DAT and docs page say how to update: dragging a `.tox` in embeds a copy, so updating means dragging in the new one (or pointing External .tox at it). [A word about external files](https://derivative.ca/community-post/word-about-external-files-202310k-builds/68166)
  The README DAT's UPDATING section and the docs page's Use it section both say to delete the copy and drag in the new blob_track.tox, or point External .tox at a downloaded file.
- [x] D6 Provenance: the README DAT's CREDITS and the docs page's Credits and license name every paper, technique, project, code, font, model and media the effect uses, follows or was built after, with links and licenses, and call original only what was designed here and has no earlier source after a search. Code recalled from elsewhere that can't be traced is replaced, never called original; code taken from elsewhere is also credited where it sits (a comment in the shader or script). D3 and check_tox.py only see that the sections exist.
  CREDITS and the docs page name the look's origin (blob-tracking overlays on social video, no files or code used), Derivative's Blob Track TOP, lowbias32 (public domain), the 5 x 7 font and WCAG 2.3.1; the GPU Grid, tracking and flash budget are written for this library. A scan of the shaders for known hashes and formulas found only lowbias32. The beat clock's tempo from the gaps between kicks is credited in both as inter-onset-interval tempo induction, the idea behind Dixon 2001, followed, not copied.
- [x] A2 The flash limits were measured, not assumed: the output recorded with a beat-heavy input at each Flashing setting, and the flashes in any one second counted.
  dev/flash.py + dev/flashcount.py on the 0.1.1 build, stress beat of 8 beats, 2 bars and 1 drop a second, on the new 5 s test clips. Worst second, area rule: dancer Off 1.0, Calm 2.0, Up to 3 per second 3.0 (clip alone 1.0); plaza 0.5, 1.5, 2.0 (clip alone 0.5); dancer with no beat 1.5 at every setting (clip alone 1.0). The 0.1.0 build on the same new dancer clip measured the same (1.0, 2.0, 3.0), so the rise from 0.1.0's 2.0 at Up to 3 comes from the new footage, not the tracker. No red flashes; all within flashcount's bars (Off at most clip + 0.5, Calm clip + 1.5, every setting 3). Re-measured on 0.1.2 (same stress beat): dancer Off 1.0, Calm 2.0, Up to 3 per second 3.0 (clip 1.0); plaza 1.0, 1.5, 2.0 (clip 0.5); with a 140 BPM beat (dev/testbed.py beat=music) 1.0, 2.0, 2.5 on the dancer. Within WCAG and each setting's rule; the same as 0.1.1 but plaza Off, 1.0 here against 0.5 (the rule allows the clip's 0.5 rounded up to 1).
- [x] A3 No meaning rests on hue alone (brightness, size or motion carries it too); the palette is colorblind-safe (orange and blue); text is legible at the size it is shown.
  Numbers above a box and positions below it differ in place and brightness as well as orange against gray; spawned links also differ by coming with the beat and fading; Accent offers orange, blue or white. Text is the 5 x 7 font at 2 px per font pixel at 720 high, with a dark outline on darker pictures; checked on 1:1 frames of both clips and in the preview (a crop, so it stays readable at 640 px). The gray position text is deliberately fainter over bright areas, which keeps it from flashing.
- [x] A4 Anything unreliable is labeled experimental in its help and docs.
  Fosfora's drop detection is marked experimental in the Song Moments help, the README DAT and the docs page. Raw-audio beat detection is marked experimental in the Scramble Labels help, the README DAT and the docs page. The wording now says raw-audio beats come from a kick detector and a beat clock that locks to the kicks' tempo, experimental: it can still add or miss beats and which beat starts a bar is a guess.
