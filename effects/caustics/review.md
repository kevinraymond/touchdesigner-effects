# caustics: idiom review

Reviewed version: 0.1.0

The review items of docs/TD_IDIOMS.md, checked by hand for this version: tick each box
(`- [x]`) and say in a few words how it holds.

- [x] P4 Pulse for actions, Toggle for states, Menu for discrete choices; labels in Title Case. Names of 10 characters or fewer are checked at save time (assert_idiomatic); TouchDesigner itself refuses names that aren't an uppercase letter followed by lowercase letters or digits. [Custom Parameters](https://docs.derivative.ca/Custom_Parameters), [Page Class](https://docs.derivative.ca/Page_Class)
  Floats for Depth, Waves, Wind, Size, Caustics, Rainbow, Refraction, Water Color, Wake, Beat Kick, Loudness and Max Distance; a Menu for Depth Type (discrete choices); an Int for Display; a Toggle for Full Screen (a state); Pulses for Open Window and Open Docs. Labels in Title Case (Water Color, Beat Kick, Depth Type, Max Distance). Water Color's name is Watercolor and Beat Kick's Kick; the longest names are Watercolor, Refraction, Fullscreen and Openwindow (10).
- [x] P5 Inner operators follow the COMP's parameters through expressions (`parent().par.Amount`), not scripts copying values; values only the inside needs are kept off the pages (`ipar`). [Internal Parameters](https://docs.derivative.ca/Internal_Parameters)
  Every inner operator follows the page through expressions: water reads Wake and the drop (Beat Kick times drop_env, where from drops); surface reads Size (the swells' length and, through it, their slope), Waves (times the loudness when input 2 is wired), Depth, the swells' clock (wind, from Wind) and whether input 3 is wired; caustics reads Rainbow; show reads Refraction, Caustics and Water Color; near reads Depth Type and Max Distance. Values only the inside needs (the sun, the index of refraction, the swells' table, their slope at Size 0.12 and period, the wakes' breadth, a drop's size, the wave equation's damping and viscosity, the glint) are constants in the builder, off the page.
- [x] P6 Related parameters are grouped with `startSection`; parameters that don't apply in the current mode are grayed out with `enableExpr`.
  Sections: Depth, Waves, Wind and Size (the water); Caustics, Rainbow, Refraction and Water Color (the light and the view); Wake, Beat Kick and Loudness (what disturbs the water); Depth Type and Max Distance (input 3); then the window. Max Distance grays out unless Depth Type is Distance in Meters. Beat Kick and Loudness stay live with nothing on input 2, as no library effect grays a parameter by its wiring; their help says they act on input 2's music.
- [x] I4 The audio input goes through `audio_in()`, which reads it by channel name with fallbacks and takes a pulse from its count channel when one exists, because a one-frame pulse is lost on any frame nothing pulls the CHOP; the effect reads the counts (`beat_count`, `bar_count`...) for logic, not `beat`. [Cook](https://docs.derivative.ca/Cook), [Logic CHOP](https://docs.derivative.ca/Logic_CHOP)
  Input 2 goes through audio_in(). counts selects beat_count and steps (a time-sliced Slope CHOP) is above 0 on the frame it rises: drop_env (a Trigger CHOP) pours each drop for 0.1 s and drops (a Count CHOP) counts them, which says where each falls. level_pick selects level and level_smooth (a Filter CHOP, 1 s) eases it for the waves. The one-frame beat channel is never read. With nothing wired, no beats come and the waves don't follow the level.
- [x] E2 Only capitalized members are promoted; state lives on `self` and the extension can be reinitialized at any time; no module globals; `onInitTD`/`onDestroyTD`, the 2025 names. [Release Notes 2025](https://docs.derivative.ca/Release_Notes/2025.30000)
  No extension in this effect, so nothing to promote or reinitialize.
- [x] C4 Motion and timing follow seconds (`absTime.seconds`, `me.time.seconds`), not frame counts, so dropped frames don't change the speed. [AbsTime Class](https://docs.derivative.ca/AbsTime_Class)
  The wave equation steps once a frame with its pull, damping and viscosity worked out from the frame's step (absTime.stepSeconds, at most 0.1 s), so a second of water is the same at any frame rate (the pull is capped where the step would go unstable, below 30 fps). The swells move by their clock, a Speed CHOP of Wind (in seconds, wrapping every 16384 s), and a drop pours its water over 0.1 s by the frame's step. The wakes come from the input's new frames, not the project's.
- [x] C5 Nothing cooks while the output is unused: checked with `dev/idle.py` (nothing downstream, the node out of view; input 2 unwired and wired to a changing beat), or in the Performance Monitor. [Performance Monitor](https://docs.derivative.ca/Performance_Monitor_Dialog)
  dev/idle.py on the final build (node viewer off, nothing downstream): 0 of 234 operators cooked over 60 frames unused, with input 2 unwired and with the clip, its depth and a beat changing every frame wired in; the controls (pulling out_top) cooked 40 and 43. The water and the swells' clock run only while something pulls the output, and the compute shader dispatches only as many workgroups as tile the caustics map.
- [x] C6 Pixel formats are 8-bit unless precision is needed, and 32-bit float for data textures (a CHOP to TOP feeding a shader).
  water is 32-bit float (heights and velocities that a frame's small changes add to); surface is 32-bit float (heights, slopes and depths in pixels, which the caustics' refraction reads exactly); push, near and the caustics map are 16-bit float (signed changes, nearness, light from 0 to about 50); show is 8-bit, the picture. The Blur TOPs (push_blur, near_soft, light) take their inputs' formats. The lib optical flow's passes keep their reviewed formats.
- [x] C7 The performance note on the docs page was measured on the reference machine at 1280 x 720, not estimated.
  dev/perf.py, three runs with /tdlib_demo paused (dev/probes/demo_pause.py; MacBook Pro M2 Pro 16 GB, macOS 15.6, TouchDesigner 2025.33230), 1280 x 720, defaults, the dancer's depth on input 3, stress beat: GPU 2.20, 2.20, 1.93 ms (95th percentile 2.52, 2.54, 3.14), CPU 0.40, 0.39, 0.43 ms, 60 fps held each time; the page gives 2.2 ms (2.5) and 0.4 ms. Costliest: caustics 0.83 to 0.97 (the compute gather of a 640 x 360 map), push_blur 0.20 to 0.26, show 0.15 to 0.18, near_soft 0.14, surface 0.13 to 0.14.
- [x] D5 The README DAT and docs page say how to update: dragging a `.tox` in embeds a copy, so updating means dragging in the new one (or pointing External .tox at it). [A word about external files](https://derivative.ca/community-post/word-about-external-files-202310k-builds/68166)
  The README DAT's UPDATING section and the docs page's Use it section both say to delete the copy and drag in the new caustics.tox, or point External .tox at a downloaded file.
- [x] D6 Provenance: the README DAT's CREDITS and the docs page's Credits and license name every paper, technique, project, code, font, model and media the effect uses, follows or was built after, with links and licenses, and call original only what was designed here and has no earlier source after a search. Code recalled from elsewhere that can't be traced is replaced, never called original; code taken from elsewhere is also credited where it sits (a comment in the shader or script). D3 and check_tox.py only see that the sections exist.

The docs page names the earlier water and caustics (exsstas's MIT Wave_ripples.tox, the alltd GLSL tutorial, a RayPOP scene, Adobe After Effects' Caustics and Wave World), the patents searched and how the effect keeps clear of the active ones (NVIDIA US 11,830,125 and 12,315,070, ByteDance US 11,854,121), and what was tried and set aside (raindrops all the time, fine wakes, pushing the water's velocity). Original, after a search: the picture as the pool's floor, the swells from a build-time table, the wakes and drops on the beat, the gather done a patch at a time in shared memory, the depth from input 3.

- [x] A3 No meaning rests on hue alone (brightness, size or motion carries it too); the palette is colorblind-safe (orange and blue); text is legible at the size it is shown.
  Nothing is signaled by color: the light's net reads by brightness, the water's blue is a tint, and Rainbow's fringes decorate lines that read by their brightness. No text in the output.
- [x] A4 Anything unreliable is labeled experimental in its help and docs.
  The cut that keeps a new shot from slamming the water is a heuristic (lib clock.glsl's), labeled experimental in the README DAT and on the docs page. The rest is deterministic.
