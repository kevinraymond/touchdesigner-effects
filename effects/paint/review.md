# paint: idiom review

Reviewed version: 0.1.1

The review items of docs/TD_IDIOMS.md, checked by hand for this version: tick each box
(`- [x]`) and say in a few words how it holds.

- [x] P4 Pulse for actions, Toggle for states, Menu for discrete choices; labels in Title Case. Names of 10 characters or fewer are checked at save time (assert_idiomatic); TouchDesigner itself refuses names that aren't an uppercase letter followed by lowercase letters or digits. [Custom Parameters](https://docs.derivative.ca/Custom_Parameters), [Page Class](https://docs.derivative.ca/Page_Class)
  Menus for Style and Depth Type (discrete choices); Toggles for Half Size, Song Moments and Full Screen (states); Floats for Brush, Sharpness, Stretch, Texture, Lines, Line Width, Ink Level, Depth Brush, Max Distance, Beat Kick, Loudness and Length; Ints for Passes and Display; Pulses for Open Window and Open Docs. Labels in Title Case (Half Size, Line Width, Ink Level, Depth Brush, Beat Kick, Song Moments). The longest names are Depthbrush and Depthtype (10 and 9), and the build passes the save-time name check.
- [x] P5 Inner operators follow the COMP's parameters through expressions (`parent().par.Amount`), not scripts copying values; values only the inside needs are kept off the pages (`ipar`). [Internal Parameters](https://docs.derivative.ca/Internal_Parameters)
  Every inner operator follows the page through expressions: kuwahara1-3's radius (Brush, times 1.5 for Watercolor, times swell), Sharpness and 1 / Stretch; the Switch kuwahara (Passes) and painted (Half Size), kuwahara1's resolution (Half Size); near's Depth Type and Max Distance; brush_scale's Depth Brush and the sweep (Beat Kick, 0 in Ink); dog's Line Width; paint's Style, Lines, Ink Level and Texture; swell's Loudness and Song Moments; drop_env's Length. No script copies values. The papers' constants (samples along a radius, the tensor's smoothing, k, sigma_m, eps and phi for the lines, p and phi for Ink, the sweep's time and width, the wash's breadth) live in the builder, off the page.
- [x] P6 Related parameters are grouped with `startSection`; parameters that don't apply in the current mode are grayed out with `enableExpr`.
  Sections: Style to Texture (the painting), Lines to Ink Level (the lines), Depth Brush to Max Distance (input 3), Beat Kick to Length (the music), then the window. Lines grays out for Ink, Ink Level unless Style is Ink, Max Distance unless Depth Type is Distance in Meters, Beat Kick for Ink (it doesn't sweep) and Length with Song Moments off. Line Width applies to every style (Ink's lines too) and stays live.
- [x] I4 The audio input goes through `audio_in()`, which reads it by channel name with fallbacks and takes a pulse from its count channel when one exists, because a one-frame pulse is lost on any frame nothing pulls the CHOP; the effect reads the counts (`beat_count`, `bar_count`...) for logic, not `beat`. [Cook](https://docs.derivative.ca/Cook), [Logic CHOP](https://docs.derivative.ca/Logic_CHOP)
  Input 2 goes through audio_in(). counts selects beat_count and drop_count, and a time-sliced Slope CHOP (steps) turns each rise into a one-frame step: beat_now starts sweep (a Trigger CHOP ramping 0 to 1 over 0.35 s) and counts beat_n (each sweep's direction), drop_now starts drop_env. level is read as a level (level_smooth) and build as a level in swell. Nothing reads the one-frame beat channel. With nothing wired no step comes, and swell holds 1 (the loudness term needs a source).
- [x] E2 Only capitalized members are promoted; state lives on `self` and the extension can be reinitialized at any time; no module globals; `onInitTD`/`onDestroyTD`, the 2025 names. [Release Notes 2025](https://docs.derivative.ca/Release_Notes/2025.30000)
  No extension in this effect, so nothing to promote or reinitialize.
- [x] C4 Motion and timing follow seconds (`absTime.seconds`, `me.time.seconds`), not frame counts, so dropped frames don't change the speed. [AbsTime Class](https://docs.derivative.ca/AbsTime_Class)
  Everything follows seconds: a sweep crosses in 0.35 s (a Trigger CHOP's attack), a drop rises in 0.3 s, holds Length seconds and settles over 0.8 s (a Trigger CHOP), and the loudness eases over 0.5 s (a Filter CHOP). The painting itself has no state in time: each frame is painted from that frame. No shader takes a clock.
- [x] C5 Nothing cooks while the output is unused: checked with `dev/idle.py` (nothing downstream, the node out of view; input 2 unwired and wired to a changing beat), or in the Performance Monitor. [Performance Monitor](https://docs.derivative.ca/Performance_Monitor_Dialog)
  dev/idle.py on the final build (node viewer off, nothing downstream): 0 of 78 operators cooked over 60 frames unused, with input 2 unwired and with the clip, its depth and a beat changing every frame wired in; the control (pulling out_top) cooked 37 and 40. The passes not asked for don't cook (the Switch kuwahara cooks only its selected input; look.py logged kuwahara2 and 3 last cooking 160 frames before the rest), nor does upsample with Half Size off. No expression reads another operator's size: brush_scale takes its size from the picture (input 0) at a quarter, and the 1 x 1 depth_none stands in for input 3. dev/idle.py on the 0.1.1 build: 0 of 257 operators (the Network Boxes' insides included) cooked over 60 frames unused, unwired and wired; control 37 and 40.
- [x] C6 Pixel formats are 8-bit unless precision is needed, and 32-bit float for data textures (a CHOP to TOP feeding a shader).
  kuwahara1-3, upsample and paint are the input's own format (8-bit from a movie or camera): pictures. tensor, tensor_h, tensor_v and flow are 16-bit float RGBA: squared gradients and a unit vector, which 8 bits would round away in flat areas. dog and lic are 16-bit float RG (two blurred brightnesses whose small difference is the line). brush_scale is mono 16-bit float (a scale of 0.5 to 6). near is lib depth_near's 16-bit float. mean is an Analyze TOP's 1 x 1. No CHOP-to-TOP data textures.
- [x] C7 The performance note on the docs page was measured on the reference machine at 1280 x 720, not estimated.
  dev/perf.py on the final build, three runs with /tdlib_demo paused (MacBook Pro M2 Pro 16 GB, macOS 15.6, TouchDesigner 2025.33230), 1280 x 720, defaults, stress beat: GPU 5.28, 5.37, 5.26 ms (95th percentile 5.86, 7.16, 5.73), CPU 0.38, 0.39, 0.37 ms, 60 fps held each time; the page gives the medians, 5.3 ms (5.9) and 0.37 ms. Costliest: kuwahara1 about 3.8 ms, flow 0.4, lic 0.3. One run each: Half Size 4.24 ms (kuwahara1 1.71, upsample 0.43), Passes 2 6.54 ms. GPU times wandered by a third or more between runs (flow, a fixed amount of work, read 0.26 to 0.50 ms; board #4692), which the page says. 0.1.1 only lays the network out (Network Boxes, positions), drops the unused compute shaders and holds the README to one line per paragraph: dev/probes/structure_diff.py against 0.1.0 finds every other operator, parameter, expression and wire unchanged, so these numbers stand.
- [x] D5 The README DAT and docs page say how to update: dragging a `.tox` in embeds a copy, so updating means dragging in the new one (or pointing External .tox at it). [A word about external files](https://derivative.ca/community-post/word-about-external-files-202310k-builds/68166)
  The README DAT's UPDATING section and the docs page's Use it section both say to delete the copy and drag in the new paint.tox, or point External .tox at a downloaded file.
- [x] D6 Provenance: the README DAT's CREDITS and the docs page's Credits and license name every paper, technique, project, code, font, model and media the effect uses, follows or was built after, with links and licenses, and call original only what was designed here and has no earlier source after a search. Code recalled from elsewhere that can't be traced is replaced, never called original; code taken from elsewhere is also credited where it sits (a comment in the shader or script). D3 and check_tox.py only see that the sections exist.
  CREDITS and the docs page name Kyprianidis, Kang and Doellner 2009 (DOI linked) for the anisotropic Kuwahara filter, Kyprianidis, Semmo, Kang and Doellner 2010 (DOI linked) for the polynomial weights and Listing 1's two sets of 4, Kyprianidis and Doellner NPAR 2011 (PDF linked) for the structure tensor as used, with Jaehne, Scharr and Koerkel 1999, Di Zenzo 1986, Brox et al. 2006 and Yang et al. 1996; Winnemoeller, Kyprianidis and Olsen 2012 (DOI linked) for XDoG, after Kang, Lee and Chui 2007, and Cabral and Leedom 1993 for the line integral; Bousseau et al. 2006 (DOI linked) for Watercolor, saying the layers are drawn here with noise; Perlin 2002 and lowbias32 (public domain, linked) for the noise; Kopf et al. 2007 for Half Size and Williams 1983 for mipmaps; yeataro's (GPL-3.0) and ogrew's (MIT) Kuwahara as seen, not used; Dixon 2001 for the beat clock, followed; WCAG 2.3.1; and the preview footage (CC BY 4.0, AI-generated). The papers were read from their PDFs while building; the shaders are written from their equations (each shader's header cites its source). Nothing recalled from elsewhere: the Godot shader and a blog post the search turned up were not opened. The turned sampling grid with mipmap levels, the pairing of opposite samples, the canvas weave, the depth and the music are written for this library, not called original.
- [x] A2 The flash limits were measured, not assumed: the output recorded with a beat-heavy input at each Flashing setting, and the flashes in any one second counted.
  No Flashing setting. dev/flash.py + dev/flashcount.py on the final build, stress beat of 8 beats, 2 bars and 1 drop a second, the demo paused. Worst second, area rule / red (clip alone): dancer 1.0 / 0 (1.0 / 0); 140 BPM 1.0 / 0; no beat 1.0 / 0; plaza 0.5 / 0 (0.5 / 0); flowers 0.5 / 1.5 (1.0 / 1.0); koi 0.5 / 1.5 (0.5 / 1.5); Beat Kick 1 and Loudness 1 on the dancer 1.0 / 0 and on the flowers 0.5 / 2.0; plaza Beat Kick 1 0.5 / 0; Watercolor dancer 1.0 / 0, flowers 0.5 / 1.5; Ink dancer 1.0 / 0, flowers 1.0 / 0; Depth Brush 1 on the dancer 1.0 / 0; 3 passes on the koi 0.5 / 2.0. All within WCAG's 3; the defaults add nothing beyond the count's half-flash margin. Found and fixed: Ink's sweeps flipped patches between ink and paper, 2.0 on the flowers and 1.5 on the dancer against the clips' 1.0, and 1.0 with Beat Kick 0 (with Song Moments off it stayed 2.0, so the drops weren't it), so Ink doesn't sweep. The red flashes follow the clips' own (the flowers' and koi's reds sit near WCAG's line); at the corner Beat Kick 1 with Loudness 1 the flowers came to one more a second, within WCAG. 0.1.1 only lays the network out (Network Boxes, positions), drops the unused compute shaders and holds the README to one line per paragraph: dev/probes/structure_diff.py against 0.1.0 finds every other operator, parameter, expression and wire unchanged, so these numbers stand.
- [x] A3 No meaning rests on hue alone (brightness, size or motion carries it too); the palette is colorblind-safe (orange and blue); text is legible at the size it is shown.
  Nothing is signaled by color. Oil and Watercolor keep the picture's own colors (Watercolor a little lighter), and Ink is near-black on warm white, which reads by brightness. No text in the output.
- [x] A4 Anything unreliable is labeled experimental in its help and docs.
  Fosfora's drop detection is marked experimental in the Song Moments help, the README DAT and the docs page; raw-audio beats are marked experimental in the README DAT and the docs page. Nothing else is unreliable: the painting is the same every time for the same frame.
