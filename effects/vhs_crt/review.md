# vhs_crt: idiom review

Reviewed version: 0.1.0

The review items of docs/TD_IDIOMS.md, checked by hand for this version: tick each box
(`- [x]`) and say in a few words how it holds.

- [x] P4 Pulse for actions, Toggle for states, Menu for discrete choices; labels in Title Case. Names of 10 characters or fewer are checked at save time (assert_idiomatic); TouchDesigner itself refuses names that aren't an uppercase letter followed by lowercase letters or digits. [Custom Parameters](https://docs.derivative.ca/Custom_Parameters), [Page Class](https://docs.derivative.ca/Page_Class)
  Toggles for Tape, Head Switching, Screen, Song Moments and Full Screen (states); Menus for Tape Speed, Signal, Mask, Bursts and Flashing (discrete choices); Floats for Wear, Tracking, Mask Size, Scanlines, Curvature, Glow and Length; Ints for Lines and Display; Pulses for Open Window and Open Docs. Labels in Title Case; the longest names are Headswitch (10) and Scanlines, Curvature (9), and the build passes the save-time check.
- [x] P5 Inner operators follow the COMP's parameters through expressions (`parent().par.Amount`), not scripts copying values; values only the inside needs are kept off the pages (`ipar`). [Internal Parameters](https://docs.derivative.ca/Internal_Parameters)
  Every inner operator follows the page through expressions: the GLSL uniforms (parent().par.Tape, Wear, Tracking, Headswitch, Lines, Screen, Masksize, Scanlines, Curvature, Glow, and Speed, Signal and Mask by menuIndex), the raster's height (resolutionh = parent().par.Lines on line_in, tape, deck and signal), the burst requests' gains (Bursts, Moments), the burst's hold (Length), the slip (Moments) and the gate and budget (Flashing). No script copies values. The tape speeds' bandwidths, the sharpening, the raster width, the steady period, the slip, the glow's blur, the flash spacing, the band's height limit and the red guard's knee stay in the builder and shaders, off the page.
- [x] P6 Related parameters are grouped with `startSection`; parameters that don't apply in the current mode are grayed out with `enableExpr`.
  Sections: Tape to Head Switching (the tape), Signal and Lines, Screen to Glow (the tube), Bursts to Song Moments (the music), then Flashing, then the window. Tape Speed, Wear, Tracking and Head Switching gray out with Tape off; Mask, Scanlines, Curvature and Glow with Screen off; Mask Size with Screen off or Mask None; Length with Bursts Off. dev/probes/vhs_enable.py on the built .tox: each follows its toggle or menu.
- [x] I4 The audio input goes through `audio_in()`, which reads it by channel name with fallbacks and takes a pulse from its count channel when one exists, because a one-frame pulse is lost on any frame nothing pulls the CHOP; the effect reads the counts (`beat_count`, `bar_count`...) for logic, not `beat`. [Cook](https://docs.derivative.ca/Cook), [Logic CHOP](https://docs.derivative.ca/Logic_CHOP)
  Input 2 goes through audio_in(). counts selects beat_count, bar_count and drop_count; a time-sliced Slope CHOP (steps) turns each rise into a one-frame step. Beat steps drive the kick (beat_env); the burst requests follow bars (or beats) and drops, and the burst's own number (burst_count) seeds its band, which holds still while it lasts. level (noise) and build (tracking) are read as levels. The beat channel is never read.
- [x] E2 Only capitalized members are promoted; state lives on `self` and the extension can be reinitialized at any time; no module globals; `onInitTD`/`onDestroyTD`, the 2025 names. [Release Notes 2025](https://docs.derivative.ca/Release_Notes/2025.30000)
  No extension in this effect, so nothing to promote or reinitialize.
- [x] C4 Motion and timing follow seconds (`absTime.seconds`, `me.time.seconds`), not frame counts, so dropped frames don't change the speed. [AbsTime Class](https://docs.derivative.ca/AbsTime_Class)
  Everything follows absTime.seconds: the tape's fields (59.94 a second, for the noise and jitter), the tracking band's crawl and drift, the edge wave and flagging, the steady clock; the kick's envelope (a 0.3 s Trigger CHOP decay), the burst's hold (Length) and fade (0.15 s), the slip (held while the burst is), and the gate and budget (re-trigger delays in seconds). Nothing counts frames.
- [x] C5 Nothing cooks while the output is unused: checked with `dev/idle.py` (nothing downstream, the node out of view; input 2 unwired and wired to a changing beat), or in the Performance Monitor. [Performance Monitor](https://docs.derivative.ca/Performance_Monitor_Dialog)
  dev/idle.py on the final 0.1.0 build (node viewer off, nothing downstream): 0 of 61 operators cooked over 60 frames unused, with input 2 unwired and with the clip and a beat changing every frame wired in; the control (pulling out_top) cooked 40 and 41. The raster's height is an expression on the Lines parameter, not on another operator's size, and the glow's size follows the source through the resolution menu (eighth).
- [x] C6 Pixel formats are 8-bit unless precision is needed, and 32-bit float for data textures (a CHOP to TOP feeding a shader).
  The raster (line_in, tape, deck, signal) is 16-bit float: YIQ's color channels go negative, and the filters sum dozens of taps. The glow's source is 16-bit float, being linear light (8-bit bands in the dark). The output (screen) follows its input's format, 8-bit for an 8-bit picture. No data textures.
- [x] C7 The performance note on the docs page was measured on the reference machine at 1280 x 720, not estimated.
  dev/perf.py on the final 0.1.0 build, three runs (MacBook Pro M2 Pro 16 GB, macOS 15.6, TouchDesigner 2025.33230), 1280 x 720, defaults: GPU 3.45, 2.94, 2.91 ms (95th percentile 4.35, 3.45, 3.38), CPU 0.42, 0.30, 0.30 ms, 60 fps held each time; the page gives the median, 2.9 ms GPU and 0.30 ms CPU. Costliest: tape 1.0 ms, deck 0.9 ms. An earlier build measured 2.14 ms; GPU times on this Mac swing about a third between runs.
- [x] D5 The README DAT and docs page say how to update: dragging a `.tox` in embeds a copy, so updating means dragging in the new one (or pointing External .tox at it). [A word about external files](https://derivative.ca/community-post/word-about-external-files-202310k-builds/68166)
  The README DAT's UPDATING section and the docs page's Use it section both say to delete the copy and drag in the new vhs_crt.tox, or point External .tox at a downloaded file.
- [x] D6 Provenance: the README DAT's CREDITS and the docs page's Credits and license name every paper, technique, project, code, font, model and media the effect uses, follows or was built after, with links and licenses, and call original only what was designed here and has no earlier source after a search. Code recalled from elsewhere that can't be traced is replaced, never called original; code taken from elsewhere is also credited where it sits (a comment in the shader or script). D3 and check_tox.py only see that the sections exist.
  CREDITS and the docs page name NTSC (FCC 1953, SMPTE 170M) and VHS's published bandwidths; ntsc-rs (MIT OR ISC OR Apache-2.0, checked in its Cargo.toml), ntscqt and ntsc (Apache-2.0) and composite-video-simulator (GPL-2.0), whose source was read for the order of a tape's passes and its causal filters, no code taken (ntsc-rs's ntsc.rs and filter.rs were read; the shaders here are written from the bandwidths, and the cutoffs differ); the textbook NTSC receiver; CRT-Geom (GPL) and Lottes' shader (public domain) for brightness-dependent Gaussian scanlines and masks, followed, not copied; halation as the common blurred mix; lowbias32 (public domain, credited in lib/glsl/common.glsl where it sits); the components seen in the survey; the beat clock (Dixon 2001, followed); WCAG 2.3.1. The bursts, the slip and the red guard are written for this library. A scan of the shaders found only lowbias32, the standard YIQ matrices, one-pole filter poles, Gaussian and Hann-windowed sinc kernels.
- [x] A2 The flash limits were measured, not assumed: the output recorded with a beat-heavy input at each Flashing setting, and the flashes in any one second counted.
  dev/flash.py + dev/flashcount.py on the final 0.1.0 build, stress beat of 8 beats, 2 bars and 1 drop a second, 600 frames each. Worst second, area rule, Off / Calm / Up to 3 per second (clip alone): dancer 1.0 / 1.0 / 1.5 (1.0); dancer at 140 BPM 1.0 / 1.0 / 1.0 (1.0); dancer with no beat 1.0 at every setting (1.0); plaza 0.5 / 0.5 / 1.0 (0.5); flowers 1.0 / 1.0 / 1.5 (1.0); koi 1.0 / 1.0 / 1.5 (0.5); flowers at Wear 1, Tracking 1, EP 1.0 / 2.0 / 2.5 (1.0). Red: 0 everywhere (the flowers alone 1.0, the koi 1.5). All within flashcount's bars. Earlier builds failed and were changed (board #4678): a roll on drops (3.5 at Up to 3, 3.0 at Calm), composite's field-to-field phase flip and the tape's noise on reds near WCAG's 80% line (red 2.0 at Off on the flowers), the mask's red stripes over orange (red 2.5 at Off, worst case).
- [x] A3 No meaning rests on hue alone (brightness, size or motion carries it too); the palette is colorblind-safe (orange and blue); text is legible at the size it is shown.
  Nothing is signaled by color: the bleeding, the noise and the mask are the look, and the bursts carry their timing by a band of torn lines across the picture. No text is drawn. The red guard keeps very saturated reds short of WCAG's saturated-red line.
- [x] A4 Anything unreliable is labeled experimental in its help and docs.
  Fosfora's drop detection is marked experimental in the Song Moments help, the README DAT and the docs page; raw-audio beats are marked experimental in the README DAT and the docs page (a kick detector and a beat clock that can still add or miss beats; which beat starts a bar is a guess).
