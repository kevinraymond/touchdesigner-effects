# touchdesigner-effects

A library of drop-in TouchDesigner effects: one self-contained `.tox` each, generated by a
builder script, checked at save time, released as GitHub release assets.

- `docs/BRIEF.md` is the brief: what every effect promises and the TouchDesigner lessons
  learned building Fosfora's component. Read it before designing an effect.
- `private/research.md` (gitignored, local only): the survey, the gaps and the first ten
  effects. Product research stays out of the public repo.
- `docs/BUILDING.md`: layout, builder shape, save-time checks, manifests, dev loop, releasing.

## Commands

```sh
uv run tests/test_guards.py          # each stale-file guard still fails when broken
uv run tests/check_tox.py            # every .tox in step with its sources (pre-commit + CI)
dev/td.sh dev/selftest.py            # in TouchDesigner: each save-time check refuses when broken
dev/td.sh effects/<n>/build_<n>.py   # build an effect in TouchDesigner, copy the .tox back
dev/td.sh dev/demo.py                # after every build: load it into /tdlib_demo, where Kevin watches it grow
dev/td.sh bundles/showreel/build_showreel.py   # then the showreel, which embeds every effect
```

## Rules

- `.tox` files are generated, never hand-edited. Change the sources, rebuild, and commit the
  `.tox` with its `.json` manifest. Changing anything in `lib/` means rebuilding every effect.
  Building or adding an effect means rebuilding the showreel too (check_tox.py fails until then).
- Builders start from `new_effect()` and end with `finish_effect()` + `save_effect()`; see
  the builder shape in docs/BUILDING.md. Fill docked DATs with `docked()`; never add a second one.
- Name each part of a network with `section()`, titled in plain words; `finish_effect()` lays the
  network out in Network Boxes and `assert_laid_out` checks it (docs/BUILDING.md, Laying out the
  network). Never place operators by hand. A README holds one line per paragraph.
- Each new check gets broken once on purpose: plain-Python checks in `tests/test_guards.py`,
  save-time checks in `dev/selftest.py`.
- `docs/TD_IDIOMS.md` is a box to check: the auto items are save-time checks, and every effect
  version gets the review items ticked in `effects/<name>/review.md` (check_tox.py enforces it).
- Flashing follows WCAG 2.3.1: an effect that can flash uses `new_effect(flashing=True)` (Off /
  Calm default / at most 3 per second) and the limits are measured on its output.
- Input order is alphabetical by In operator name (`in1_top`, `in2_audio`), not node position.
- Every change goes to `main` through a pull request, squash-merged (a ruleset enforces it): work
  on a branch, push it, `gh pr create`. The title becomes the commit subject and a line of the
  release notes, so write it as the commit subject; the description becomes the commit message.
  See Releasing in docs/BUILDING.md.
- Nothing under `dev/` ships. Builds from the dev loop land in `/tdlib_dev` on the Mac.
- US English spelling everywhere: identifiers, parameter labels, docs, file names.
