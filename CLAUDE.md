# tdlib: TD Effects Library

A library of drop-in TouchDesigner effects: one self-contained `.tox` each, generated by a
builder script, checked at save time, released as GitHub release assets.

- `docs/BRIEF.md` is the brief: what every effect promises and the TouchDesigner lessons
  learned building Fosfora's component. Read it before designing an effect.
- `docs/research.md`: the survey, the gaps and the first ten effects (milestone 1).
- `docs/BUILDING.md`: layout, builder shape, save-time checks, manifests, dev loop, releasing.

## Commands

```sh
uv run tests/test_guards.py          # each stale-file guard still fails when broken
uv run tests/check_tox.py            # every .tox in step with its sources (pre-commit + CI)
dev/td.sh dev/selftest.py            # in TouchDesigner: each save-time check refuses when broken
dev/td.sh effects/<n>/build_<n>.py   # build an effect in TouchDesigner, copy the .tox back
```

## Rules

- `.tox` files are generated, never hand-edited. Change the sources, rebuild, and commit the
  `.tox` with its `.json` manifest. Changing `lib/tox_build.py` means rebuilding every effect.
- Builders start from `new_effect()` and end with `finish_effect()` + `save_effect()`; see
  the builder shape in docs/BUILDING.md. Fill docked DATs with `docked()`; never add a second one.
- Each new check gets broken once on purpose: plain-Python checks in `tests/test_guards.py`,
  save-time checks in `dev/selftest.py`.
- Input order is alphabetical by In operator name (`in1_top`, `in2_audio`), not node position.
- Nothing under `dev/` ships. Builds from the dev loop land in `/tdlib_dev` on the Mac.
- US English spelling everywhere: identifiers, parameter labels, docs, file names.

before running. Never save or close the user's open project.
